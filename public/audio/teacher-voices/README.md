# Teacher Voice Audio Files

This directory should contain the audio files for the TIE Subject Teacher voice selection feature.

## Required Files

- `female-voice.mp3` - Female voice audio file
- `male-voice.mp3` - Male voice audio file

## File Format

- Format: MP3 (recommended) or other browser-supported audio formats (WAV, OGG)
- Quality: Clear, professional voice recordings
- Language: English (or Swahili if available)

## Usage

These audio files are played when users click the "Read" button in the TIE Subject Teacher assistant. The file selection is based on the user's voice preference (male/female) selected via the avatar or settings menu.

## Note

If audio files are not available, the system will display an error message to the user. Please ensure both files are present for the feature to work correctly.
